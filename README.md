# HORDE: генератор толпы / walla (VST3)

Один экземпляр плагина превращает 1–8 дублей (каналы входа) в толпу из 1–100 виртуальных голосов.
У каждого голоса своя задержка, сдвиг высоты с медленным «плаванием», тембр (формантная окраска),
дистанция (громкость + завал верхов + реверб), место в стерео и «качели» громкости.
Все голоса делят один общий реверб с выбором комнаты (Field / Courtyard / Hall / Cathedral).

## Роутинг в Reaper (одна шина, никаких копий дорожек)

1. Дубли лежат на своих дорожках как обычно (например 3 мужских + 3 женских, моно).
2. Создайте дорожку **CROWD**. Кнопка **Route** → **Track channels: 8**.
3. Повесьте на CROWD плагин **HORDE**. Пин-коннектор по умолчанию: вход 1…8 = каналы дорожки 1…8.
4. С каждой дорожки-дубля сделайте **Send** на CROWD:
   - Audio: источник **Mono source → 1**, назначение **1** для первого дубля, **2** для второго и т.д.
   - Мужские дубли ставьте на первые каналы (1, 2, 3…), женские после них.
   - На дорожках-дублях снимите галку **Master send**, если не хотите слышать сухой дубль отдельно
     (сухой сигнал можно подмешать ручкой **Dry** в самом плагине).
5. В плагине: **Takes** = сколько дублей подали, **Male takes** = сколько первых каналов мужские.
6. Ручкой **Voices** выбираете размер толпы, **REROLL** перебрасывает все случайности (новый вариант толпы).

Совет: дубли от одного даббера лучше разнести по разным каналам, а не склеивать в один,
тогда толпа звучит богаче и меньше «хоруса».

## Параметры

| Блок | Параметр | Диапазон |
|---|---|---|
| Crowd | Voices / Takes / Male takes / M-F balance | 1–100 / 1–8 / 0–8 / M…F |
| Time & Pitch | Delay min / Delay spread / Pitch spread / Drift | 5–100 мс / 0–500 мс / 0–50 ct / 0–30 ct |
| Color & Space | Timbre / Humanize / Distance / Depth spread / Width / Reverb / Room size | 0–100 % |
| Output | Dry / Wet | 0–100 % / −24…+12 дБ |
| Room | Field / Courtyard / Hall / Cathedral | — |

Двойной клик по ручке возвращает значение по умолчанию. Окно масштабируется за правый нижний угол.
Нагрузка: 100 голосов ≈ 30 % одного ядра (48 кГц), 40 голосов примерно втрое меньше.

## Сборка под Windows

### Вариант А: GitHub Actions (без установки чего-либо)
Залейте папку в репозиторий GitHub. Workflow `.github/workflows/build-windows.yml` соберёт плагин;
готовый `HORDE.vst3` скачивается во вкладке **Actions → последний запуск → Artifacts**.

### Вариант Б: локально
1. Установите **Visual Studio Build Tools (2022 или новее)** с компонентом «Разработка классических приложений на C++»,
   а также **CMake** и **Git**.
2. В папке проекта:
   ```
   cmake -B build -A x64
   cmake --build build --config Release --target HORDE_VST3
   ```
   JUCE 8.0.4 скачается автоматически.
3. Готовый плагин: `build\HORDE_artefacts\Release\VST3\HORDE.vst3`.

## Установка
Скопируйте папку `HORDE.vst3` в `C:\Program Files\Common Files\VST3\`, в Reaper:
Options → Preferences → Plug-ins → VST → **Re-scan**.

## Структура
- `Source/CrowdEngine.*`: DSP (голоса, питч-шифтер на двух отводах, фильтры, реверб).
- `Source/PluginProcessor.*`: параметры, шина входа на 8 каналов, сохранение состояния.
- `Source/PluginEditor.*`: интерфейс (полностью векторный, без картинок).
- `Test/`: офлайн-рендер и снимок интерфейса (`-DHORDE_BUILD_TESTS=ON`).
